# 🚀 Деплой на Render (бесплатно)

Render — единственный доступный бесплатный хостинг в 2026 (Koyeb закрылся). Бот работает через **webhook**, карта не нужна.

> ⚠️ Бесплатный сервис засыпает через 15 минут без трафика, но **просыпается** при новом сообщении. Первое сообщение после паузы — задержка до ~1 минуты.

## Шаг 1. Код на GitHub

Репозиторий `school-suggest-bot` должен содержать файлы проекта (см. папку). Если менял код — просто заново загрузи файлы через **Add file → Upload files** (GitHub обновит совпадающие).

## Шаг 2. Render

1. Открой [render.com](https://render.com) → **Sign up** (через GitHub или Google). Карта не нужна.
2. Нажми **New + → Web Service**.
3. **Connect GitHub** → разреши доступ → выбери репозиторий `school-suggest-bot`.
4. Настройки:
   - **Language/Runtime:** Docker (Render сам найдёт `Dockerfile`).
   - **Instance Type:** **Free**.
   - **Region:** Frankfurt / Germany (Европа).
5. Раздел **Environment Variables** — добавь 4 переменные:
   ```
   BOT_TOKEN=9070049667:AAHFNgusAIrMf8pHZWSCWjDMJBCZ4s6vRWg
   ADMIN_IDS=9031297139
   CHANNEL_ID=-1004409860661
   MODERATION_CHAT_ID=9031297139
   ```
6. Нажми **Create Web Service** и дождись статуса **Live** (2–3 минуты).

## Шаг 3. Проверка

1. Render даст адрес вида `https://school-suggest-bot.onrender.com`.
2. Открой `.../health` → должно вернуть **`ok`**.
3. В Telegram напиши боту `/start` → отправь тестовый пост.
4. Пост придёт **в твою личку** с кнопками → **✅ Одобрить** → он появится в канале анонимно. 🎉

## Как это работает

- Код сам берёт адрес из переменной `RENDER_EXTERNAL_URL` и ставит webhook на `.../webhook`.
- Порт берётся из `PORT` (Render задаёт автоматически).
- База SQLite эфемерная: при передеплое обнулится (посты всё равно уходят в канал).

## Если что-то не так

- **Статус не Live / ошибка сборки** — проверь, что `Dockerfile` есть в репозитории.
- **`/health` не открывается** — подожди 1–2 минуты после деплоя.
- **Бот молчит** — проверь 4 переменные окружения (особенно `BOT_TOKEN`).
- Скинь скрин ошибки Render — подскажу.
