# 🎭 Школьная «предложка» — анонимный Telegram-бот

Бот для школьной подслушки: пользователи анонимно присылают сообщения, админы модерируют и публикуют их в канал.

## ✨ Возможности

- **Полностью анонимно** — в канале никто не видит, кто отправил пост.
- **Модерация** — посты сначала попадают админам, которые жмут «Одобрить» / «Отклонить».
- **Любой контент** — текст, фото, видео, голосовые, кружки, документы, стикеры и альбомы из нескольких фото/видео.
- **Админ-панель** — просмотр профиля отправителя, **мут** (1 ч / 6 ч / 1 день / 7 дней) и **бан**.
- **Статистика** — команда `/stats`.
- **SQLite** — простая база без настройки.

## 🚀 Быстрый старт (локально)

### 1. Получи токен бота
1. Открой [@BotFather](https://t.me/BotFather).
2. Напиши `/newbot`, придумай имя и username бота.
3. Скопируй выданный **токен** (выглядит как `1234567890:ABC-DEF...`).

### 2. Подготовь канал и чат модерации
- Создай канал, куда будут публиковаться посты. **Добавь бота админом** в этот канал.
- Реши, куда падают посты на проверку:
  - вариант А — личка админа (просто начни диалог с ботом и напиши `/id`);
  - вариант Б — отдельная группа модераторов (добавь туда бота и всех админов, напиши `/id` в группе).

### 3. Узнай нужные ID
- **Твой ID / ID чата** — напиши боту `/id` (работает после запуска) или используй бота [@getmyid_bot](https://t.me/getmyid_bot).
- **ID канала** — перешли любое сообщение из канала в [@getmyid_bot](https://t.me/getmyid_bot), он покажет ID вида `-100...`.

### 4. Настрой `.env`
```bash
cd school-suggest-bot
cp .env.example .env   # на Windows: copy .env.example .env
```
Открой `.env` и заполни:
```ini
BOT_TOKEN=твой_токен
ADMIN_IDS=твой_id,id_второго_админа
CHANNEL_ID=-100...
MODERATION_CHAT_ID=твой_id_или_id_группы
```

### 5. Установи и запусти
```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/macOS

pip install -r requirements.txt
python main.py
```

Готово! Бот запущен. Отправь ему сообщение — оно придёт в чат модерации.

## 🛠 Команды и кнопки

**Для всех:**
- `/start` — приветствие
- `/help` — правила
- просто отправь сообщение — оно уйдёт на модерацию

**Для админов (в чате модерации):**
- Кнопки под постом: **✅ Одобрить**, **❌ Отклонить**, **👤 Профиль**, **🔨 Бан**, **🔇 Мут**
- `/stats` — статистика
- `/id` — узнать ID чата и свой ID
- `/ban <id>` (или ответ на сообщение) — забанить
- `/unban <id>` — разбанить
- `/mute <id> <минуты>` (или `/mute <минуты>` ответом) — замутить

## ☁️ Деплой на хостинг (24/7)

### Render (простой)
1. Залей проект на GitHub.
2. На [render.com](https://render.com) — **New → Web Service**, выбери репозиторий.
3. Runtime: **Python 3**, Build command: `pip install -r requirements.txt`, Start command: `python main.py`.
4. В разделе **Environment** добавь переменные `BOT_TOKEN`, `ADMIN_IDS`, `CHANNEL_ID`, `MODERATION_CHAT_ID`.
5. Выбери **Background Worker** тип (бесплатный тариф засыпает после простоя — для тестов ок).

### Railway
1. Залей проект на GitHub.
2. На [railway.app](https://railway.app) — **New Project → Deploy from GitHub repo**.
3. Добавь переменные окружения (те же 4 штуки). В проекте уже есть `Procfile`.

### VPS (любой)
```bash
# после клонирования и настройки .env
pip install -r requirements.txt
# запуск в фоне
nohup python main.py > bot.log 2>&1 &
```

## ⚠️ Важно про базу

База — это файл `data/bot.db` (SQLite). На бесплатных хостингах с **эфемерным диском** (Render/Heroku) файлы стираются при перезапуске. Чтобы данные не терялись:
- либо подключи **Persistent Disk / Volume** и храни `data/` там,
- либо позже переведи бота на PostgreSQL (я могу дописать — скажи).
